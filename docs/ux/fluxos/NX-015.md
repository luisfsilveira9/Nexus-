# Fluxo NX-015 — Progresso que nunca se perde

> RN: 015 (v0.3; e 009: pausa; 011: o aviso de save vem antes da T13; 012: t_off; 018: ordem). Telas: T00 Carregando, T12a/b/c, A05,
> T14 Ajustes, T16 Exportar, T17 Importar. Wireframes: `../wireframes/T00-T12-carregar-e-save.html`,
> `../wireframes/T14-ajustes.html`.

## Objetivo do jogador
"Quero fechar o app a qualquer hora sem medo, e ter uma cópia minha do clube."

## Fluxo de abertura

```
abrir ─► T00 Carregando (logo [ARTE] + "Carregando o clube…"; sem barra falsa)
           ├─ cópia atual ok ────────────────────────────► fila normal (T13 / T07 / aba)
           ├─ cópia atual não confere, a outra é válida ──► T12a [Dona Cel] "Recuperamos seu clube"
           │      "Não deu para ler o último save. Carregamos a cópia anterior, de hoje às
           │       14:32 (10 s antes)." [ Continuar ] ─────► fila normal
           └─ nenhuma cópia válida ──────────────────────► T12b [Dona Cel] "Não conseguimos abrir seu save"
                  [ Tentar de novo ]  [ Começar clube novo ]  (mesmo tamanho)
                  [ Exportar o save que não abriu ]           (secundário, 48 px)
                     │                       └─► T12c "Começar um clube novo?"
                     │                             [ Cancelar ] [ Começar clube novo ]
                     │                             └─► save ilegível guardado ─► T01 Prólogo
                     └─► T00 de novo ─ falhou ─► T12b "Ainda não abriu (2ª vez)"
```

- Save editado à mão que não confere conta como corrompido (RN-015): cai nos mesmos casos. Também
  conta como corrompida a cópia com checksum certo mas valor impossível (ouro negativo, divisão
  inexistente, nome fora da RN-019 v0.3.1, por exemplo com emoji).
- Nada disso mostra a barra de abas, então o relógio de partida fica parado (RN-009 v0.3).
- A Dona Cel (48 px, decorativa) acompanha T12a/b/c (ADR-003); o título em texto diz tudo sem ela.
- O save é silencioso: sem ícone piscando nem "salvando…". A T14 mostra "Último save: há 4 s".
- Não existe botão "Salvar": o jogador nunca é responsável por salvar.

## Exportar e importar (T14 → T16 / T17)

```
T14 Ajustes ─ Save ─ [Exportar] ─► T16 painel: texto do save (prévia), resumo "Faísca eSports · FSC ·
                                   Elite · Legado 25 · agora", [Copiar texto] [Salvar arquivo], [Fechar]
                                   ─ Copiar ─► A04 "Copiado." (não mexe no jogo)
             └─ [Importar] ─► T17 painel: [Colar] [Escolher arquivo]
                     ├─ texto inválido/alterado ─► "⚠ Esse texto não é um save válido. Ele está
                     │     incompleto ou foi alterado. Seu clube atual continua igual." (Usar desabilitado)
                     ├─ versão mais nova que o jogo ─► "⚠ Este save é de uma versão mais nova do jogo.
                     │     Atualize o jogo (feche e abra de novo) e tente outra vez." (Usar desabilitado)
                     └─ válido ─► prévia "Faísca eSports · FSC · Elite · Legado 25 · salvo em 18/11, 21:04"
                           [Cancelar] [Usar este save]
                               └─► modal "Trocar o clube atual?" (sai X, entra Y)
                                     [Exportar o atual primeiro]
                                     [Cancelar] [Trocar clube]
                                        └─► reabre pela fila de abertura (T00 → T12 → T13 → T06 → T07 → A03),
                                            com t_off contado a partir do `maior` do save importado,
                                            máx. 8 h (RN-015 v0.3, P-UX-11 decidido)
```

- Exportar está sempre disponível; Ajustes lembra, sem pressão, que exportar protege contra limpar
  os dados do navegador (ADR-002).
- Com save ilegível guardado (depois da T12c), a T14 mostra a linha "Save que não abriu ·
  [Exportar]". O formato do arquivo e do texto é do `nexus-tech`.
- Nunca apaga um save válido sem confirmação: a troca por importação exige o modal, com o clube que
  sai e o que entra e o atalho "Exportar o atual primeiro" (abre a T16 sobre o modal; ao fechar a
  T16, o modal continua aberto). Sem save válido atual (depois da T12b), não há o que confirmar.

## Estados

| Estado | Tela | O que se vê |
|---|---|---|
| **Carregando** | T00 | Logo + texto; depois de 3 s: "Ainda carregando…" (sem % inventada) |
| **Primeira vez** | T00 → T01 | Sem save: prólogo com nome padrão (Faísca eSports / FSC) |
| **Sucesso** | — | Nada a mostrar; segue a fila |
| **Cópia recuperada** | T12a | ⚠ + título + hora da cópia + perda estimada; 1 botão |
| **Nenhuma cópia válida** | T12b | Duas opções de mesmo peso + exportar o ilegível |
| **Tentou de novo e falhou** | T12b | "Ainda não abriu (2ª vez)", mesmas opções |
| **Confirmar clube novo** | T12c | Cancelar e Começar do mesmo tamanho; o ilegível continua guardado |
| **Fechou à força** | — | Reabre até 10 s antes, sem aviso (perda aceita pela RN-015) |
| **Sem espaço / falha ao salvar** | A05 | "⚠ Sem espaço para salvar. Seu último save (há 2 min) está seguro. Libere espaço no aparelho." Fixo no topo, fecha com ✕, volta se continuar |
| **Exportar** | T16 | Texto + Copiar / Salvar arquivo; A04 "Copiado." |
| **Importar inválido** | T17 | Mensagem com o que aconteceu e o que fazer; nada muda |
| **Importar versão mais nova** | T17 | "Este save é de uma versão mais nova do jogo" + o que fazer; nada muda |
| **Importar válido** | T17 | Prévia de quem é o save + confirmação de troca com "Exportar o atual primeiro" |
| **Depois de importar** | T00… | Fila de abertura normal; T13 se o tempo desde o `maior` do save importado for ≥ 60 s |
| **Offline/retorno** | — | A T13 vem depois da T12, contada a partir do momento da cópia carregada |

## Ligação com critérios de aceite
- "Save corrompido": T12a antes de qualquer outra tela.
- "Nenhum save válido": T12b com "Tentar de novo" e "Começar clube novo"; T12c confirma; o ilegível
  fica para exportar (T12b e T14).
- Condição técnica "exportar/importar como texto": T16 e T17.
