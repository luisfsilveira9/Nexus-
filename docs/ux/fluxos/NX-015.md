# Fluxo NX-015 — Progresso que nunca se perde

> RN: 015. Telas: T00 Carregando, T12 Save recuperado / ilegível, T14 Ajustes (info do save).
> Wireframes: `../wireframes/T00-T12-carregar-e-save.html`, `../wireframes/T14-ajustes.html`.

## Objetivo do jogador
"Quero fechar o app a qualquer hora sem medo."

## Fluxo

```
abrir ─► T00 Carregando (logo [ARTE] + "Carregando o clube…"; sem barra falsa)
           ├─ save atual ok ─────────────────────────► fila normal (T13 / T07 / T02)
           ├─ save atual ilegível, há save válido ───► T12a "Recuperamos seu clube"
           │      "O último save não pôde ser lido. Carregamos o de hoje, 14:32
           │       (cerca de 2 min antes). Seu progresso desde então pode ter se perdido."
           │      [ Continuar ]           (único botão; o save ilegível fica guardado)
           │                                   └─► fila normal
           └─ nenhum save válido ─────────────────────► T12b "Não conseguimos ler seu save"
                  "Seu progresso está guardado, mas não conseguimos abrir agora."
                  [ Tentar de novo ]  [ Começar clube novo ]  (mesmo tamanho)
                                         └─► confirmação: "O save antigo continua guardado e
                                             pode ser recuperado depois" [Cancelar] [Começar]
                                             (comportamento a decidir: P-UX-06)
```

- O save é silencioso: sem ícone piscando nem "salvando…" (a cada 10 s seria ruído). A T14 mostra
  "Último save: há 4 s" para quem quiser conferir.
- O jogador nunca é o responsável por salvar; não existe botão "Salvar".

## Estados

| Estado | Tela | O que se vê |
|---|---|---|
| **Carregando** | T00 | Logo + texto; se passar de 3 s: "Ainda carregando…" (sem número de % inventado) |
| **Primeira vez** | T00 → T01 | Sem save: vai para Boas-vindas |
| **Sucesso** | — | Nada a mostrar; segue a fila |
| **Save corrompido com backup** | T12a | Aviso com ⚠ + título + data/hora do save carregado + perda estimada; 1 botão |
| **Sem nenhum save válido** | T12b | Duas opções de mesmo peso; "Começar clube novo" pede confirmação e não apaga o antigo |
| **Fechou à força** | — | Reabre no estado de até 10 s antes, sem aviso (perda dentro do aceitável da RN-015) |
| **Offline/retorno** | — | A T13 vem depois da T12, com base no momento do save carregado |
| **Erro ao salvar** (disco cheio etc.) | Aviso A01 em `cor.estado.aviso` | "Não deu para salvar agora. Vamos tentar de novo." Persistente até salvar; tech define gatilho |

## Ligação com critérios de aceite
"Save corrompido: o último save válido é carregado e eu sou avisado" → T12a.
