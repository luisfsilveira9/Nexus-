# Fluxo NX-010 — Tocar e comprar geradores

> RN: 001–006, 017. Telas: T02 Clube, T03 Geradores. Wireframes: `../wireframes/T02-principal.html`,
> `../wireframes/T03-geradores.html`.

## Objetivo do jogador
"Quero ver meu ouro crescer e saber o que comprar agora."

## Fluxo principal

```
T02 ─ toca no botão de toque ─► +X de ouro (feedback "+X" sobe do botão)
 │
 ├─ card "Próxima compra" (T02) ─ toca ─► compra ×1 do gerador sugerido ─► ouro cai, renda sobe,
 │                                         card mostra a próxima sugestão
 │
 └─ aba Geradores (T03) ─► escolhe lote ×1 / ×10 / Máx (fixo embaixo)
                         └─► toca "Comprar" na linha ─► compra o lote ─► save (RN-015)
```

### Regra da "Próxima compra" (T02)
Proposta de UX, só escolhe entre itens que já existem nas RN:
1. Entre os geradores **visíveis**, o de **menor custo da próxima unidade**.
2. Se nenhum é comprável agora, mostra esse mesmo gerador desabilitado com "Faltam X".
3. Não sugere elenco (para não decidir pelo jogador entre as duas trilhas); a meta da T02 cuida
   disso (ver NX-012).
4. A T02 compra sempre ×1. Lote só na T03, para evitar gasto grande por toque acidental.

### Linha de gerador (T03)
`[ícone] Nome [LORE: gerador N]` · `n 37 · +18,5/s` (renda total do gerador) · barra "37/50 ·
faltam 13 para ×2" (RN-004) · botão `Comprar ×10 · 1,02 mil` (56 px de altura, 108 px de largura).
Nomes longos cortam com reticências; o "faltam X" e o custo nunca são cortados.

### Botão de toque (T02)
- Rótulo `[LORE: nome do botão, provisório "Fazer live"]` + `+X por toque` (X = max(1; 0,1 × renda/s),
  formato `taxa`).
- Toques acima de 5/s: ignorados **sem aviso** (RN-005); o feedback visual só aparece para toques
  que contaram, assim o jogador não vê "+X" que não recebeu.
- Feedback: escala 0,96 por `duracao.rapida` + "+X" subindo (`duracao.lenta`). Com "Reduzir
  animações": só a mudança de escala. Vibração curta opcional (T14, desligada por padrão).

## Acessibilidade
- Botão de toque com nome acessível "`[LORE: botão]`, ganha X de ouro"; não exige toque rápido para
  progredir (os geradores rendem sozinhos).
- Seletor de lote: 3 segmentos de 104×48 px, selecionado com fundo + negrito + `aria-pressed`.

## Ligação com critérios de aceite
- "Comprar o primeiro gerador": ouro `0`, renda `+0,5/s`, próximo custo `11` — depende da exceção
  de casas decimais (P-UX-01), senão a renda apareceria `+0/s`.
- "Toque limitado" e "Máx sem ouro" cobertos pelos estados acima.
