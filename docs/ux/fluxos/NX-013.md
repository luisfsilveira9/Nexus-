# Fluxo NX-013 — Enquanto você esteve fora

> RN: 011, 012 (e 016, 017). Tela: T13. Wireframe: `../wireframes/T13-offline.html`.

## Objetivo do jogador
"Quero ver, sem esforço, o que o clube fez enquanto eu estava fora."

## Fluxo

```
T00 Carregando ─► (T12 se save recuperado) ─► t_off válido ≥ 60 s? ─ não ─► aba anterior
                                                      │ sim
                                                      ▼
                                      T13 Enquanto você esteve fora
                                       ├─ Tempo fora:   7 h 12 min
                                       ├─ Ouro:        +1,44 mi
                                       ├─ Partidas:     5 jogadas · 4V 1D
                                       ├─ Temporada:    terminou · Subiu para Desafiante (se terminou)
                                       └─ [ Receber ]  (56 px, metade de baixo)
                                                      │ (voltar do sistema / toque fora = Receber)
                                                      ▼
                                      credita → save → (T07 se subiu a divisão inédita) → T02
```

- **Limite de 60 s** para mostrar a T13 é proposta de UX (abrir e fechar o app rápido não deve
  gerar uma tela por nada). O ganho continua sendo creditado mesmo abaixo de 60 s, só que sem a
  tela. **Conflito possível com "nada é creditado antes de o jogador ver essa tela" (RN-011)** →
  pedido P-UX-04.
- Ordem dos blocos: tempo → ouro (maior, `texto.numero.grande`) → partidas → temporada. Ouro e V-D
  são os números que o jogador procura.
- Animação de contagem do ouro (`duracao.lenta`) só para enfeite; o número final aparece por
  inteiro sem animação com "Reduzir animações". Tocar em "Receber" durante a contagem credita na
  hora.
- Um só botão. Sem "dobrar", sem anúncio, sem oferta (RN-011, RN-016).

## Estados

| Estado | O que se vê |
|---|---|
| **Primeira vez** (1º retorno da vida) | Igual ao padrão + linha de apoio: "Fora do jogo, o clube rende metade e joga até o fim da temporada. Conta até 8 h." `[LORE]` |
| **Retorno curto** (< 60 s) | Não abre a T13 (proposta, P-UX-04) |
| **Retorno padrão** | Tempo, ouro, partidas e V-D. Se 0 partidas (< 90 s fora): linha "Nenhuma partida jogada" |
| **Mais de 8 h** (RN-012) | Tempo mostra o real ("10 h 05 min") e apoio "Contamos as 8 h máximas". Sem tom de punição |
| **Temporada terminou fora** | Bloco extra com seta + "Subiu / Ficou / Caiu" e o placar final; "A próxima temporada começa agora" |
| **Temporada já estava acabada** (todas as 14 jogadas antes de sair) | Não ocorre: a nova temporada começa com o app aberto (RN-010) |
| **Partidas paradas no fim da temporada** | Se havia tempo para mais partidas: "Partidas param no fim da temporada" (explica por que foram só 5) |
| **Relógio atrasado** (t_off < 0, RN-012) | T13 **não aparece**; ganho 0; nenhum erro mostrado ao jogador (nada foi perdido). Registro só em log técnico |
| **Renda zero** (antes do 1º gerador) | Ouro `+0`; se também não houve partida, T13 não aparece |
| **Carregando** | A T00 cobre o cálculo; a T13 só aparece com os números prontos |
| **Erro de cálculo** | Não mostrar número errado: se o cálculo falhar, ir para a T02 sem crédito e registrar erro técnico (tech decide); nunca creditar parcialmente sem mostrar |
| **Save corrompido** | T12 primeiro; a T13 usa o momento do save recuperado (diz isso no aviso da T12) |
| **Subiu a divisão inédita** | Depois de "Receber", abre o T07 Capítulo |

## Ligação com critérios de aceite
"Volta depois de 10 horas": `+1,44 mi`, `5 jogadas`, temporada terminou, T13 antes de qualquer
outra tela (exceto T12, que é aviso de sistema — confirmar no P-UX-04). "Relógio atrasado": T13
não aparece, ganho 0.
