# Fluxo NX-017 — Capítulo curto a cada divisão nova

> RN: 010 (e 013: capítulos vistos são mantidos). Telas: T07 Capítulo, T08 Jornada (reler), A03.
> Wireframe: `../wireframes/T07-capitulo.html`.

## Objetivo do jogador
"Quero sentir a jornada sem ser obrigado a ler."

## Fluxo

```
T06 Fim de temporada "Subiu para Desafiante" ─ Continuar ─┐
T13 (temporada terminou fora com subida) ─ Receber ───────┤
                                                          ▼
                              capítulo da divisão já visto? ─ sim ─► A03 "De volta à Desafiante" (3 s)
                                                          │ não
                                                          ▼
                              T07 Capítulo [LORE: título] · Capítulo 2 de 6
                                 texto curto (< 1 min de leitura, até ~150 palavras [LORE])
                                 [ Pular ]  [ Continuar ]  (mesmo tamanho, embaixo)
                                                          ▼
                              marca como visto → T02

T08 Jornada ─ lista "Capítulos" ─ toca num visto ─► T07 em modo releitura (botão único "Fechar")
```

- "Pular" e "Continuar" fazem a mesma coisa (marcam como visto e fecham); "Pular" existe para o
  jogador não sentir que precisa ler. O capítulo fica disponível na T08.
- Capítulos são texto (e, se a arte quiser, uma ilustração no topo); sem áudio no MVP.
- Rolagem interna só se a fonte do sistema estiver grande; botões ficam fixos embaixo.

## Estados

| Estado | O que se vê |
|---|---|
| **Primeira vez** (1º capítulo, Desafiante) | T07 com apoio "Capítulos ficam salvos na Jornada" |
| **Vazio** (T08 sem capítulos) | "Seu 1º capítulo aparece quando o clube subir de divisão." + capítulos futuros como "Capítulo 2 — Desafiante · travado" (cadeado + texto) |
| **Releitura** | T07 sem "Pular"; botão "Fechar" |
| **Já visto, divisão de novo** (pós-prestígio ou depois de cair e subir) | A03, sem T07 (NX-017; ver P-UX-07) |
| **Duas subidas seguidas sem abrir o app** | Não ocorre: offline para no fim da temporada (RN-011) |
| **Texto ainda não escrito** | Placeholder `[LORE: capítulo N]`; o QA trata como bloqueio de aceite, não de build |
| **Carregando / erro** | Texto é local; sem estado de carregamento |
| **Save corrompido** | Capítulos vistos vêm do save recuperado; um capítulo pode reaparecer se a subida foi depois do save válido |
