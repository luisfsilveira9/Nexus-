# Fluxo NX-014 — Refundar o clube (prestígio)

> RN: 013, 014. Telas: T08 Jornada, T09 etapa 1, T10 etapa 2, T11 resultado.
> Wireframe: `../wireframes/T08-jornada-e-prestigio.html`. Nome final `[LORE: prestígio, provisório
> "Refundar o clube"]`.

## Objetivo do jogador
"Quero saber quando vale recomeçar e exatamente o que ganho e perco."

## Fluxo

```
T08 Jornada ─ card "Refundar o clube"
   ├─ TRAVADO   (melhor divisão da run < Academy): cadeado + "Chegue à Academy" + trilha
   │            "Melhor divisão desta run: Desafiante". Botão desabilitado "Travado".
   └─ DISPONÍVEL: "Você ganha 10 de Legado" + [ Ver o que muda ] (56 px)
                         │
                         ▼
   T09 Etapa 1 — resumo (tela cheia, rolável se fonte grande)
      Ganha:  +10 Legado (total 0 → 10)
      Bônus:  renda +0% → +50% · poder +0% → +10%
      Zera:   ouro (1,23 mi), 6 geradores, níveis dos 5 jogadores, divisão (volta à Amadora),
              temporada atual (6V 3D)
      Mantém: Legado, capítulos vistos, estatísticas, ajustes
      Se subir mais antes de refundar: Liga = 25 · Internacional = 45 · Mundial = 80
      [ Voltar ]  [ Continuar ]   (mesmo tamanho, lado a lado, 156×56 cada)
                         │
                         ▼
   T10 Etapa 2 — confirmação (modal)
      "Refundar agora? Ouro, geradores, níveis e divisão voltam ao início."
      [ Cancelar ]  [ Refundar ]   (mesmo tamanho; "Refundar" em cor.estado.perigo + texto)
      Toques nos primeiros 500 ms após abrir são ignorados (anti toque duplo), sem contagem visível.
                         │
                         ▼
   T11 Clube refundado: "Legado 10", "+50% renda · +10% poder já ativos", [ Começar ] → T02
```

- Duas etapas em telas diferentes, com toques diferentes (RN-013). Não usar "segure para
  confirmar" como única forma (difícil para quem tem tremor); se a arte quiser, pode ser opção extra.
- Os números da T09 vêm da run atual; se uma partida terminar com a T09 aberta e a melhor divisão
  mudar, a T09 atualiza o valor e mostra "Atualizado: agora você ganha 25". Na T10 vale o valor
  exibido; se mudar enquanto a T10 está aberta, ela volta para a T09 (ou o relógio pausa:
  P-UX-05).
- Sem pressão: o card disponível na T08 não pisca, não tem contagem e a meta da T02 só cita a
  refundação uma vez ("Refundação disponível na Jornada"), quando fica disponível pela primeira vez
  na run.

## Estados

| Estado | Onde | O que se vê |
|---|---|---|
| **Primeira vez** (1ª vez disponível na vida) | T08, T02 | Aba "Jornada •"; meta da T02: "Refundação disponível na Jornada". No card: 1 frase de explicação "Recomece do zero com bônus permanente." |
| **Travado** | T08 | Cadeado + "Chegue à Academy" + melhor divisão da run. Texto, não só ícone (critério NX-014) |
| **Disponível** | T08 | Legado que ganharia agora + botão "Ver o que muda" |
| **Etapa 1** | T09 | Ganha / bônus antes → depois / zera (com valores atuais) / mantém |
| **Etapa 2** | T10 | Confirmação curta, Cancelar e Refundar de mesmo tamanho |
| **Cancelou** | T09/T10 → T08 | Volta sem nenhuma mudança; nenhuma mensagem de culpa |
| **Sucesso** | T11 → T02 | Legado novo, bônus ativos; T02 em Amadora, `0V 0D`, ouro 0, T03 vazia |
| **Sem ouro / vazio** | — | Não se aplica: prestígio não custa ouro |
| **Offline/retorno** | — | A run continua; se subir de divisão fora, o Legado do card atualiza ao voltar |
| **Erro ao refundar** | T10 | Se o save da refundação falhar: nada muda, aviso "Não deu para refundar agora. Seu clube está como antes." + Tentar de novo. Nunca estado intermediário |
| **Save corrompido** | — | NX-015 |

## Ligação com critérios de aceite
- "Prestígio indisponível": texto "Chegue à Academy" no card travado.
- "Refundar depois da Liga": T09 mostra +25, renda +125% (×2,25), poder +25% (×1,25); T11 confirma;
  T02 volta ao início.
